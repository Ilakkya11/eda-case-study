# Dataset

This project loads the Wisconsin Breast Cancer Diagnostic dataset through `sklearn.datasets.load_breast_cancer(as_frame=True)`. No external download is required. Original source and citation: https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic

Target mapping used: 0 = malignant, 1 = benign. The dataset is not duplicated here to keep the repository small.
